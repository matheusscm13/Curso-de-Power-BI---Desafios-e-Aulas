# Curso-de-Power-BI---Desafios-e-Aulas

🚀 Trilha Power BI & Data Analytics — Digital Innovation One (DIO)
Este repositório foi criado para consolidar todos os projetos, desafios práticos e relatórios desenvolvidos durante o meu aprendizado na trilha de Power BI e Análise de Dados promovida pela Digital Innovation One (DIO).

📌 Visão Geral do Repositório
O objetivo deste repositório é documentar minha evolução técnica, centralizando estudos sobre modelagem de dados, linguagem DAX, construção de dashboards interativos e storytelling com dados.
